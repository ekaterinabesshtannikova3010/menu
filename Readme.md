# Django Tree Menu App

## Описание
Django app, который реализовывает древовидное меню.
## Установка
1. Убедитесь, что у вас установлен Python и Poetry.
2. Склонируйте репозиторий:
```bash
   git clone &lt;repository_url&gt;
   cd &lt;repository_folder&gt;
Установите зависимости:
   poetry install
Примените миграции базы данных:
   poetry run python manage.py migrate
Создайте суперпользователя, чтобы получить доступ к панели администратора:
   poetry run python manage.py createsuperuser
Использование
Добавление пунктов меню в админке
Перейдите в админ-панель (обычно по адресу /admin) и добавьте пункт меню через интерфейс.

Отрисовка меню
Чтобы нарисовать меню на странице, используйте следующий синтаксис в вашем шаблоне:

{% load tags %}
{% draw_menu 'main_menu' %}
Активные пункты меню
Активные пункты меню определяются на основе URL текущей страницы.
